# wordplai icon

`icon.svg` is the approved AI waiter/typewriter logo inherited from the original
wrAIter artwork. The legacy folder and filenames remain for compatibility.
The PNG exports are rendered directly from that SVG at their named pixel sizes;
`icon.ico` contains the 16, 24, 32, 48, 64, 128 and 256 px Windows frames.

Word embeds its ribbon PNG and window ICO in the DLL and ships the ICO for its
installer and Windows installed-app entry.

`social-preview.png` is the 1280 × 640 repository/share image using this same
mark. It is prepared for GitHub's repository social-preview setting; its presence
in the checkout does not mean it has been uploaded there. README links use the
SVG directly. See the [download page](https://georgefejer91.github.io/wordplai/download/).
