# Agents Inc and application state

Agents Inc supplies technology-specific guidance alongside the shared
housekeeping and product skills. Read only the matching companion. Installing
agent guidance does not add a library to an application.

| Task | Companion | Existing owner and overlap |
| --- | --- | --- |
| Evaluate MobX or change an existing MobX boundary | `mobx-integration` | Preserve current state owners; GSD retains the plan/checklist |
| HTML names, keyboard behavior, focus, announcements, or accessibility evidence | `agents-inc-accessibility` | Pretext owns geometry; use one interaction/layout matrix |
| Measured browser/WebView performance issue or explicit budget | `agents-inc-web-performance` | Use one profiling record; MobX owns reactive dependencies, Tauri owns native behavior |

## MobX adoption

MobX is optional for JavaScript/TypeScript application state. Assess the current
solution before adoption. Preserve adequate component state, existing state
managers, server caches, routers, persistence, and native authorities. A
suitability review alone does not authorize a dependency or architecture change.

For Tauri, Rust remains the application authority. MobX can hold UI intent and
validated projections using the existing typed commands, receipts, and revision
rules. It must not duplicate native access control or durable ownership.
For games, evaluate menus, inventory, settings, and editors separately from
frame-critical simulation. Expand high-frequency observable coverage only with
evidence from the actual target.

React bindings apply only to React. Preserve the chosen framework. The MVVM
example informs service boundaries; its custom transforms, DI, and claims about
hooks are project choices. Use standard MobX APIs and the existing composition.

copies. Three topics were selected: MobX, web accessibility, and web performance.

per-file source hashes. They are distributed in this repository's `skills/`

another skill only for a current consumer after reviewing its instructions,
provenance, and overlap. Do not activate all frameworks or testing tools.
